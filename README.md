# FluoriVenger
Clear, action‑oriented, addresses the specific health threat of fluorosis


The Main Trick – “Local Bio‑Mineral Filters”
Everyone assumes fluoride removal requires expensive imported activated alumina or reverse osmosis. The trick: use crushed bone char (from local slaughterhouses) mixed with clay and maize cobs – a known, low‑cost adsorbent. By partnering with Kenya’s Meat Commission, you get waste material for free, then bake it into affordable filter cartridges.
